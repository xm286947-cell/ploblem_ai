# REPEAT_CASE_ENGINE V2.0 — M7.2.6/M7.2.7 Delivery

## Scope

- M7.2.6 Query Enricher Pipeline
- M7.2.7 Single-query and batch validation

## Added

- `builder/query_enricher.py`
- CLI command `run-m72`
- Pipeline summary `output/logs/m72_pipeline_summary.json`
- Pipeline tests for full run, AI degradation, stage rerun, and failure isolation

## Commands

```bash
# Full batch pipeline with real configured model
python main.py run-m72 --overwrite

# Local deterministic smoke test
python main.py run-m72 --mock --overwrite

# Degraded mode without AI
python main.py run-m72 --skip-ai --overwrite

# Single query
python main.py run-m72 --query-id QUERY001 --mock --overwrite

# Rerun AI and Builder only
python main.py run-m72 --from-stage ai --query-id QUERY001 --overwrite

# Rerun Builder only
python main.py run-m72 --from-stage build --query-id QUERY001 --overwrite
```
