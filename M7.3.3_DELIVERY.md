# REPEAT_CASE_ENGINE V2.0 M7.3.3 交付说明

本版本完成：

- M7.3.1 Retrieval Profile Schema
- M7.3.2 Retrieval Profile Builder
- M7.3.3 现有 Retriever 接口适配

## 新增命令

```bash
python main.py run-m73-profile --overwrite
python main.py run-m73-retrieve --overwrite
```

单条执行：

```bash
python main.py run-m73-profile --query-id QUERY001 --overwrite
python main.py run-m73-retrieve --query-id QUERY001 --top-k 10 --overwrite
```

## 输出

```text
knowledge/retrieval_profile/{query_id}.json
output/candidate_cases/{query_id}.json
output/logs/m73_profile_summary.json
output/logs/m73_retriever_summary.json
```

本版本只完成 Retrieval Profile 生成及与现有 Retriever 的兼容适配。Structured Filter、Multi-channel Recall、Candidate Merge 与初始排序将在后续版本实现。
