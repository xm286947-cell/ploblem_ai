# V0.7.1 展示术语基线

原则：内部 canonical key 保持稳定；面向用户统一采用“中文（English）”展示。

| Canonical | 用户展示 | 示例值 |
|---|---|---|
| capacity | 容量（Capacity） | 1 Gbit |
| nand_type | 单元类型（Cell Type） | 单层单元（SLC） |
| pe_cycles | 擦写次数（P/E Cycle） | 100K 次（cycles） |
| retention | 数据保持（Data Retention） | 10 Years |
| ecc_requirement | ECC能力（ECC Capability） | 4 bits / 528 bytes |
| bad_block_requirement | 坏块管理（Bad Block Management） | 1004 blocks / Bad Block Mark |
| program_time | 编程时间（Program Time） | 400 μs |
| erase_time | 擦除时间（Erase Time） | 3 ms |

原始 AI 候选和证据永远保留，不用中文翻译去覆盖原始事实；中文（English）仅用于结构化字段和值的展示归一。
