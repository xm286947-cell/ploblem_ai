# V0.8.0-RC1 / RC2 验收说明

## 验收目标
RC1 验“资料读对、身份唯一”；RC2 验“只抽寿命/诊断、形成审核后规格”。

## RC1 检查项
- PDF 上传后原件保留。
- `document.md` 生成，按页包含 `# Page N`。
- 常规表格尽量保留为 Markdown Table；失败不阻断。
- 文档号、Revision、版本日期、状态、分支、语言可查询。
- 同一 SHA-256 重复导入被拦截。
- 同一 Document Number + Variant + Revision + Language 的逻辑重复被拦截，即使二进制不同。
- 新 Revision 可并存，并显示库内新旧状态。
- catalog 只作为官方快照提示，不代替 PDF 证据。

## RC2 检查项
- NAND/NOR/eMMC/SSD 的默认分析字段只围绕寿命与诊断。
- Raw Candidate 与 Reviewed Specification 分层。
- `SLC NAND Flash` 等旧语义可收敛为 Cell Type。
- Capacity / P-E 等价候选可归并证据。
- ECC / Bad Block 机制性长句不占默认 Reviewed Specification。
- Final Review 仍可分批处理，截断不会导致整单失败。
