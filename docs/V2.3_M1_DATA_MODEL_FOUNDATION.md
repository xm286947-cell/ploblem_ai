# REPEAT_CASE_ENGINE V2.3 M1 — Data Model Foundation

## Status

Engine Delivery

## Scope

This milestone introduces the V2.3 data-contract foundation without migrating M6/M7/M8 business pipelines.

Delivered capabilities:

- Versioned Pydantic v2 DTOs;
- native primitive fields for source facts;
- `EvidenceField[T]` only for AI extraction/inference;
- independent decision DTOs;
- runtime JSON Schema generation;
- compact Prompt Schema generation from the same DTO;
- Schema Registry;
- unified AI output parser with field-path errors;
- conservative JSON extraction/repair;
- V2.2 compatibility adapters for M6/M7/M8 outputs.

## Compatibility

Existing V2.2 schemas and pipelines remain in place. M2–M4 will migrate business modules incrementally.
