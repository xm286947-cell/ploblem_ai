# 三工作台增量导入与重复清理 PATCH45

## 适用范围

- ITR问题工作台
- ITR彻底解决工作台
- 软件问题考核工作台

## 增量导入规则

以“数据组／工作台 + 标准ITR号”为问题身份：

1. 标准ITR号和内容均相同：跳过，不新增记录。
2. 标准ITR号相同、内容发生变化：保存为新版本。
3. 标准ITR号从未出现：新增问题。
4. 工作台默认仅展示每个问题的最新版本，旧版本不再混入当前数量、筛选和Top分布。
5. 自动关联仅关联最新版本，减少重复链接。
6. 软件考核新版本继承此前人工设置的考核年份；原始Excel字段不被修改。

## 重复问题清理

页面先显示存在旧版本的问题数、旧版本数、可安全删除数和受保护数，再由人工确认清理。

清理规则：

- 始终保留每个问题的最新版本。
- 删除无引用的旧版本及其自动关联、年份辅助记录。
- 已有人工分析、人工关联或质量场景证据的旧版本不得删除。
- 三个工作台分别清理，数据组之间不交叉删除。

## 性能

新增“数据组 + 标准ITR号 + 版本”索引；清单、筛选、分布和自动关联均以最新版本为范围，避免历史版本扩大查询结果。

## 验收

- 同一Excel重复导入只计为跳过。
- 同一问题内容变化后当前清单仍只有一条，并显示最新版本。
- 大小写或CS格式经过标准化后不产生新的问题身份。
- 安全清理删除无引用旧版本，保留带人工分析的旧版本。
- 软件考核人工年份在内容更新后继续有效。
