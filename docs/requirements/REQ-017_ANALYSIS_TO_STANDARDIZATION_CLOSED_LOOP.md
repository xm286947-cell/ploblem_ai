# REQ-017 问题分析驱动的标准识别、固化与效果验证闭环

状态：TRIAGED
优先级：P1
阶段：第三阶段

## 目标

将漏测、重大、批量和重复问题中已经确认的共性风险，转化为设计、验证、准入、变更及兼容性规则，并用后续 ITR 数据验证实施效果。

## 核心链路

```text
问题分析 → 共性机理 → 能力/控制缺口 → 标准建议
→ 人工评审 → 标准成果 → 研发流程应用 → ITR效果验证
```

## 基本要求

- 标准建议必须关联来源 ITR 和分析证据；
- 区分 AI 建议、人工确认、已发布和已验证状态；
- 记录适用产品、领域、场景、责任人、版本和验证指标；
- 能识别标准未建立、已建立未执行、已执行但无效等不同情况；
- 后续以同类问题数量、严重度、重复率和恢复时长变化验证效果。
