# PATCH53：质量场景产品分组

## 目标

质量场景库和行业与场景看板统一使用“产品配置”中的产品口径，避免产品选择、场景统计和看板分析各自形成独立枚举。

## 实现

### 质量场景库

- 产品选择项来自已启用的产品配置；
- 未选择产品时，场景清单按配置产品分组展示；
- 选择产品后，只显示该产品的质量场景；
- 场景行同时显示产品名称；
- 当前产品筛选会随“一键清理当前范围”传递，避免跨产品清理。

### 行业与场景看板

- 增加产品配置驱动的产品筛选；
- 增加产品分组摘要，展示各产品的场景数和来源问题数；
- 选择产品后，场景总数、问题总数、标准化覆盖、能力缺口、质量矩阵、业务活动和行业分布统一按该产品计算；
- 从矩阵下钻到场景库时继续携带产品范围。

## 数据规则

- 场景按 `quality_scenario.product_code` 归属产品；
- 产品显示名称按 `product_config.product_name` 解析；
- 不修改历史场景和原始问题数据；
- 未出现在产品配置中的历史产品编码仍保留显示，但不伪装为配置产品。

## 验收

使用 PLC、HMI 两个配置产品各创建一条场景：

1. 场景库首页出现两个产品分组；
2. 选择 HMI 后不再出现 PLC 场景；
3. 看板显示 PLC、HMI 两个产品摘要；
4. 选择 HMI 后所有统计只计算 HMI；
5. 矩阵下钻链接保留 HMI 产品条件。
