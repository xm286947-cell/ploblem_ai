# PATCH52：场景库产品词典名称显示修复

## 问题

AI 使用新增的产品场景词典生成质量场景后，场景详情内容正确，但质量场景库首页的“生命周期 / 业务活动场景”显示为编码。

## 原因

首页此前只使用默认 PLC 当前词典构建编码与中文名称的映射。产品专属词典中的新增编码，或同一编码在不同产品中的差异名称，无法由默认词典正确解释。

## 修复规则

- 每条质量场景仍保留生成时绑定的 `taxonomy_version_id`。
- 首页按该场景绑定的准确词典版本解析生命周期和业务活动中文名称。
- 只有历史数据未绑定词典版本时，才兼容回退到默认词典映射或原编码。
- 不迁移、不改写已生成场景、场景链路或原始业务数据。

## 验收

使用产品专属词典新增生命周期和业务活动，并生成质量场景后：

1. 场景库首页显示该产品词典中的中文生命周期名称；
2. 场景库首页显示该产品词典中的中文业务活动名称；
3. 不展示原始编码；
4. 场景详情原有内容保持不变。
