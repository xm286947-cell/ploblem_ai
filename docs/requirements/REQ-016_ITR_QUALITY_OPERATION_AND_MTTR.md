# REQ-016 ITR质量运行指标、MTTR分段与薄弱环节识别

状态：READY
优先级：P0
阶段：第二阶段

## 目标

以 ITR 客观事实为基础，建立质量运行指标，准确衡量现场响应、恢复和彻底解决效率，并识别产品、阶段和组织薄弱环节。

## 第二阶段最小范围

1. 梳理 ITR 中可用的时间、发生阶段、严重程度、产品及状态字段。
2. 明确时间节点定义、缺失规则和异常值规则。
3. 建立响应、定位、现场恢复、永久解决和完整闭环五类分段时长。
4. 支持按时间、产品、严重程度、发生阶段和领域筛选。
5. 展示样本数、字段完整率和有效样本率，不对缺失数据作默认推断。
6. 提供趋势、分布、超时问题、重复问题和薄弱环节下钻。
7. 通过 ITR 编号关联彻底解决材料，但不重复计算问题数。

## 开发前置门

- 先用真实样本确认时间字段业务含义；
- 明确“现场恢复”和“彻底解决”的组织口径；
- 输出指标字典和计算样例并由业务确认；
- 在指标口径冻结前，不直接开发正式管理看板。

## 验收原则

- 任一汇总数字都能下钻到对应 ITR；
- MTTR 能解释使用了哪两个时间节点；
- 缺失、负时长和异常长时长单独标识；
- 同一 ITR 不因存在多份材料重复统计；
- 页面始终显示统计范围、样本量和数据完整度。
