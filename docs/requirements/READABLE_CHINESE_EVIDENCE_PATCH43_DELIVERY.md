# 综合解读原始证据中文显示 PATCH43

## 问题

“场景资产／本范围综合解读”的来源证据快照使用模板默认 JSON 序列化，中文被显示为 `\\uXXXX`，难以阅读和核查。

## 修复

- 新增统一的可读中文 JSON 展示过滤器，序列化时关闭 ASCII 转义。
- 保留缩进、数组及对象层级，便于核查完整来源快照。
- 输出先进行 HTML 安全转义，再允许模板按预格式文本渲染，避免原始字段被解释成 HTML。
- 当前同类模板已检查，不存在其他来源快照使用相同 Unicode 展示方式。

## 验收

- 综合解读详情直接出现中文“连续运行72小时”。
- 页面中不出现对应的 `\\u8fde\\u7eed...` 编码。
- 既有成功、失败、重试及证据下钻流程保持可用。
