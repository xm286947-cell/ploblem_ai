# 客户质量场景画像 Demo PATCH49 交付说明

## 适用基线

V1.1 P2 RC2 Full（2026-09-01）及其后续累计补丁。保持 Windows BAT 启动入口和现有 SQLite 数据库不变。

## 本轮内容

- 客户／行业画像直接查询彻底解决单与 ITR，不再以是否已有质量场景限制问题范围。
- 同一标准 ITR 以 CS 为主体、ITR 为补充进行去重，并显示 CS、仅 ITR、来源冲突及 Agent 输入数量。
- 增加年份、开始月份、结束月份和问题领域筛选。
- 综合解读输出客户使用方式、生命周期与业务活动、系统设备、系统规模、环境工况、质量关注、客户语言痛点、业务影响、信息缺口及研发／测试核查建议。
- 系统设备只读取结构化产品与设备字段；环境工况只从问题描述、原因定位、TRC和现场记录提取，缺失保持未知。
- 画像页直接展示主题卡片和来源问题；未归纳问题显式保留。
- 已有场景资产调整为辅助参考，避免与本次数据库问题范围和时间口径混淆。

## 安装

关闭正在运行的服务，将升级包内容覆盖到现有程序目录后，继续使用原 BAT 文件启动。升级包不包含数据库、原始 Excel、运行输出、日志或密钥。
