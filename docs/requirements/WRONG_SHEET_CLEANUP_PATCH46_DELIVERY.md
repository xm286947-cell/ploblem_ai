# 误导入 Sheet 数据识别与清理 PATCH46

## 适用范围

- ITR问题工作台
- ITR彻底解决工作台
- 软件问题考核工作台

## 使用流程

1. 从对应工作台进入“清理误导入数据”。
2. 选择一个原始 Excel 字段作为识别依据。
3. 选择“包含字段／不包含字段／值包含／值不包含／值等于／值为空／值非空”。
4. 先预览命中数量、来源文件和 Sheet 分布及最多20条样例。
5. 核对无误后人工确认删除。

## 删除边界

- 只处理当前工作台，三个数据组互相隔离。
- 匹配范围是物理导入记录，包含历史版本，便于彻底清除错误 Sheet 数据。
- “值不包含”只匹配字段确实存在、但值不包含目标文本的记录；字段缺失必须使用“不包含字段”。
- 已有人工分析、人工关联或质量场景证据的记录不得删除。
- 自动关联和考核年份辅助记录随误导入记录一并清理。
- 删除错误的最新版本后，同一 ITR 的上一正确版本会重新成为当前展示版本。

## 验收标准

- 能按错误 Sheet 特有字段定位数据。
- 能按正确 Sheet 必备字段缺失定位数据。
- 预览能够显示来源文件、Sheet、行号、问题编号和版本。
- 删除后工作台数量、筛选及自动关联立即刷新。
- 三个工作台均提供相同入口和规则。
