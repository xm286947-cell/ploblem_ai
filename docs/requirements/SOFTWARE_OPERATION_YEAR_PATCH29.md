# PATCH29：软件考核问题年份

## 有效年份优先级

1. 工作台批量人工设置；
2. 导入时人工指定；
3. 从规范化 ITR 编号 `ITRYYYY...` 解析；
4. ITR 不能解析时，使用 Excel 原始年份字段；
5. 不能解析时显示未设置。

导入时人工指定会应用到本次文件中的全部软件考核记录。留空时，系统按后续优先级逐条确定。
已在工作台批量修正或导入时人工指定的年份，不会被同一文件的普通重复导入覆盖。

## 工作台

- 软件考核问题清单显示年份及来源；
- 支持按年份筛选；
- 支持勾选当前页的一条或多条问题，统一设置四位考核年份；
- 只允许修改软件考核数据，拒绝空选择、跨工作台数据及非法年份；
- 修改只写入考核年份元数据，不改变原始 Excel 字段、ITR 编号和历史材料版本。

## 下游消费

场景候选选题、质量场景资产的季度/半年度/年度统计以及本范围综合解读，读取有效考核年份。
考核月份继续读取软件考核数据的 KPI 计入月份。年份人工修正可覆盖该月份字符串中附带的年份。
