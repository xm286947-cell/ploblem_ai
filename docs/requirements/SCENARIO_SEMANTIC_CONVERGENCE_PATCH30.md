# PATCH30：质量场景语义收敛

本补丁解决四个问题：客户感知长文本无法聚类、质量关注点不清晰、环境工况缺少正式字段、客户体验只有抽象分类而没有客户语言。

## 数据链路

原始问题事实 → 典型问题（客户看到什么）→ 客户体验表述（客户希望什么）→ 质量关注点（研发测试守住什么）→ ISO质量模型与指标建议。

环境与工况独立记录：软硬件/网络/部署环境、负载与运行状态、持续时间/频次、异常扰动、极限工况，并增加受控工况分类。

## 词典原则

- 典型问题、质量关注点、环境工况优先复用通用或产品词典。
- AI无匹配项时可提出候选，必须给出定义、纳入/排除条件及与最近术语的差异。
- 候选经人工批准后成为正式词条；也可以合并到正式词条或驳回。
- 未批准候选不进入正式洞察矩阵。
- 历史场景补齐只修改新增语义和质量分类，不修改场景名称、业务活动、证据和发布状态。

## 页面和消费

- `/settings/scenario-semantics`：维护词典、原则和AI候选审核。
- 场景编辑页：新增典型问题、质量关注点、客户语言体验及结构化环境工况。
- 行业与场景看板：新增“业务活动 × 典型问题”和“环境工况 × 典型问题”。
- 场景资产解读优先消费正式质量关注点和结构化工况，旧字段作为兼容兜底。

## 升级兼容

数据库启动时增量加列并初始化通用词典；不重建场景，不改变关联问题、证据、状态和历史词典版本。原BAT启动方式不变。
