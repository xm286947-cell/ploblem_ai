# 质量场景表单信息层级 PATCH50

## 目标

降低质量场景确认时的阅读和填写负担，让用户先完成关键判断，再按需查看事实、证据与工程映射。

## 页面层级

1. 顶部关键判断：场景名称、生命周期、业务活动、状态和逆向判定理由。
2. 顶部质量定义：客户质量痛点、体验要求、典型问题、质量关注点和客户语言。
3. 中部场景事实：业务链路、系统设备、规模、用户、失效表现和业务影响。
4. 中部环境工况：环境、负载、持续时间、扰动和极限边界。
5. 底部辅助信息：适用范围、原始证据、行业变体、重复场景及标准质量模型。

## 兼容性

- 不新增数据库迁移，不修改已有字段含义。
- 所有原表单字段继续提交到原保存接口，已有场景无需重新生成。
- Windows BAT、SQLite和已有质量场景数据保持兼容。

## 验证

主测试集 502 项通过。升级包不包含数据库、原始问题数据、运行输出、日志或密钥。
