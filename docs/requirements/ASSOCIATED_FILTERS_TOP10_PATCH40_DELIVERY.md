# 关联筛选与关键行业／客户Top10 PATCH40交付说明

## 画像入口

- 行业、客户／公司、产品型号改为真实下拉选择，不再使用相互独立的自由输入列表。
- 任意一项变化后，其他选项按当前已选条件重新计算；行业与客户双向约束，不能组合出数据库中不存在的行业／公司关系。
- 行业和客户优先按已关联质量场景的去重问题数排序，再按数据库问题数排序。已有场景覆盖较多的重点行业／客户优先显示。
- 选项同时显示“场景关联问题数／数据库问题数”，便于区分已经沉淀的范围和仍待AI提炼的范围。

## 软件问题考核工作台

- 新增行业、客户、IPMT、SPDT、产品型号、产品系列、年份、月份关联筛选。
- 每个下拉选项均基于当前其他条件对应的同一批真实记录生成，并显示去重问题数；改变任意条件后立即刷新其他可选值。
- 翻页保留全部筛选条件；“按当前考核范围生成质量场景”把行业、客户、IPMT、SPDT、型号、系列和年份继续带入AI候选页。
- AI候选页同步支持上述维度的关联筛选，预览与提交使用同一筛选范围。

## 关键行业／客户分布

- 新增 `/software-operation-distribution` 简洁看板。
- 支持按业务（IPMT）、SPDT、产品型号、产品系列、年份和月份形成范围。
- 显示范围内Top10行业和Top10客户及问题数，点击可进入对应软件考核问题清单。
- 当前统计是问题数量分布，不等同故障率；未引入装机量、使用频次等分母。

## 验收

- 自动化验证行业→客户→型号的级联关系及反向过滤。
- 自动化验证Top10范围和AI候选范围使用相同关联条件。
- 自动化验证有质量场景关联的行业优先于仅有原始问题的行业排序。
- 全量自动化测试：488项通过。
