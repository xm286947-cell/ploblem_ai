# 客户／行业质量场景画像分析汇总 PATCH41

## 目标

画像不再停留在问题和场景清单，而是回答：问题主要集中在哪里、场景资产覆盖多少、当前证据能支持什么判断，以及下一步应核查什么。

## 页面能力

1. 基于当前行业、客户、产品和问题领域筛选后的全部去重 CS／ITR 问题形成统计，不受是否已有质量场景限制。
2. 展示主要产品、问题领域、Top 产品、高频业务活动及“产品 × 问题领域”矩阵。
3. 展示场景覆盖率，以及根因、原始发生阶段、客户状态的信息完备度。
4. 自动形成“当前事实 + 下一步”卡片；计数只表示问题集中度，不冒充故障率、风险率或已确认根因。
5. 人工触发 AI 综合解读完成后，在画像页直接展示共性主题、原因与漏测、适用边界、研发／测试建议、指标建议及来源问题编号。

## 证据边界

- 无场景问题参与产品、领域和数据完备度统计，但不被虚构为已有业务活动或质量属性。
- 根因字段缺失时明确提示补证，不生成确定性原因结论。
- AI 结论必须引用输入问题编号，仍需人工评审。
- 同一标准 ITR 去重后计数，CS 优先、ITR 补空规则保持不变。

## 验收

- 构造同一客户下多个产品、软件／硬件问题和部分根因缺失数据。
- 页面显示全量问题数、Top 产品、产品领域矩阵和准确的证据完备度。
- 已完成的 AI 综合解读能够在画像页直接查看，完整任务页仍保留用于证据和批次核查。
