# 人工画像解读失败诊断 PATCH42

## 修复内容

1. 不再把非业务异常统一隐藏为“检查配置、网络及额度”，保存并展示经过敏感信息脱敏的异常分类、异常类型和具体内容。
2. 客户／行业画像页直接显示最近失败原因、完成批数、失败批数及任务详情入口。
3. 任务详情展示每个单问题提取和分层归并批次的状态、模型及错误。
4. AI 返回 JSON、字段结构或证据覆盖校验不合格时自动重试一次；网络层重试仍由既有 AI 客户端负责，避免无限重复请求。
5. 分层归并阶段纳入任务进度和批次台账，能够定位失败发生在单问题提取还是汇总归并。

## 常见分类

- 默认模型配置不完整：缺少地址、模型或密钥环境变量。
- 模型接口超时：网络、代理或服务端响应超时。
- 模型输出被截断：达到输出 Token 上限。
- 模型返回内容校验失败：JSON 不完整、字段结构不符或遗漏来源问题。
- 模型接口调用失败：其他接口或运行异常，并保留脱敏后的具体错误。

## 验收

- 模拟代理连接失败，画像页和任务详情均能看到具体失败信息及失败批次。
- 模拟不完整 JSON，系统自动重试一次，仍失败时明确归类为模型返回内容校验失败。
- 成功任务、停止任务、画像全量逐问题处理和既有综合解读流程保持可用。
