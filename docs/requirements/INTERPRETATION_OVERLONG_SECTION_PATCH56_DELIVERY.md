# PATCH56：第四层归并超长字段自动收敛

## 问题

PATCH55 已解决最终归并输入上下文超限，但模型在第四层可能返回完整、可解析的 JSON，同时个别画像字段超过 140 字。旧逻辑会把整个任务判定为失败：`归并结果未按紧凑结构输出（主题最多5个，各段最多140字）`。

## 修复

- 首次发现字段超长时，自动重试并要求各文字段严格不超过 90 字；
- 若第二次返回的 JSON、主题数量和来源引用均合法，仅文字仍超长，系统自动收敛超长段落；
- 收敛同时保留段落首尾语义，不删除主题，不删除来源问题 ID；
- 结果摘要明确记录发生过格式收敛；
- 超过 5 个主题、来源引用不合法、遗漏输入问题或 JSON 不完整仍按质量门禁拦截，不以截断掩盖结构问题；
- 原失败任务继续支持从第四层失败步骤续跑，前序结果不重新调用模型。

## 验收

- 模拟第四层连续两次返回 200 字字段，任务第二次不再整单失败；
- 17 个画像字段均收敛至 140 字以内；
- 真实来源 ID 在短 ID 映射还原后保持不变；
- 综合解读及升级依赖专项测试 21 条通过；主测试目录 511 条通过。
