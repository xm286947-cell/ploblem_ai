# 综合解读来源覆盖校验 PATCH44

## 原因

AI 有时使用可读的 ITR／CS 单号引用证据，而旧校验只接受数据库内部来源 ID；多层归并时也可能遗漏个别合法来源。旧逻辑将两种情况都判为整单失败并提示“来源引用不合法或遗漏输入问题”。

## 修复规则

1. 提示词明确要求引用输入记录的 `id`。
2. 对当前批次中唯一可核验的 ITR、CS及标准化ITR号，安全映射为内部来源 ID。
3. 模型没有归纳到、但确实属于当前分析范围的问题，由系统加入 `unresolved_ids`，并在摘要中说明，不静默遗漏，也不把它编入结论。
4. 模型引用当前分析范围之外的编号、或一个编号无法唯一映射时，仍拒绝发布。
5. 最终结果保持全部输入问题均处于“有证据的分析主题”或“尚不能归纳”之一。

## 验收

- 模型以 `ITR...CS` 引用来源时，结果正常完成并保存为对应内部 ID。
- 模型遗漏一个合法输入问题时，该问题进入“尚不能归纳”，整份解读能够完成。
- 模型引用伪造或范围外来源时仍失败，防止无证据结论。
