# TARGET UAT 验收记录

在获准目标环境逐项填写；未执行项保持 `PENDING`，不得预填 `PASS`。记录样本授权依据、环境、版本、执行人、时间和证据链接。

```text
TARGET_SAMPLE_AUTHORIZED=PENDING
CURRENT_ITR_SOURCE=PENDING          # REAL / APPROVED_MASKED / SYNTHETIC
HISTORICAL_CASE_SOURCE=PENDING     # REAL / APPROVED_MASKED / SYNTHETIC

CASE_PUBLISH=PENDING
HISTORICAL_CASE_RETRIEVAL=PENDING
WHY_RELEVANT=PENDING
EVIDENCE_TRACE=PENDING
MISSED_TEST_CONTEXT_TRACE=PENDING
HUMAN_DECISION=PENDING
REFRESH_RECOVERY=PENDING
SEARCH_ERROR_SEMANTICS=PENDING
EVENT_ITR_ISOLATION=PENDING
CONFIRMED_NOT_OVERWRITTEN=PENDING
CROSS_DOMAIN_DB_ACCESS=PENDING    # NO / YES
REGRESSION_DELTA=PENDING          # 0 / N
WINDOWS_STARTUP=PENDING
WINDOWS_SHUTDOWN_NO_WINERROR32=PENDING

TARGET_ENV=PENDING
MVP_READY=NO
```

样本授权/脱敏依据：
当前 ITR ID、版本与 Source Owner：
历史 Event/Case ID、发布版本与来源：
漏测 Context ID、选择记录：
Query/Correlation ID：
Evidence ID、原始定位：
Windows 版本、Python 版本、包 SHA256：
执行人、时间、环境：
截图、日志、CI/回归证据位置：
缺陷与复测记录：

仅当真实或正式脱敏样本授权、完整业务闭环、异常语义、数据隔离、回归和 Windows 启停均通过，且 Release Gate 另行满足时，才能评估 `MVP_READY=YES`。
