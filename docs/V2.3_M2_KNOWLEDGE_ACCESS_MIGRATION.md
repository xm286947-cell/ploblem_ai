# REPEAT_CASE_ENGINE V2.3 M2 — Knowledge Access Migration

## Scope

M2 migrates the M8.1 analysis-context loading path from scattered file access to a centralized knowledge access boundary.

## Delivered

- `JsonArtifactRepository`
  - project-root path boundary validation
  - UTF-8 JSON object loading
  - optional/required read modes
  - atomic JSON writes
  - artifact listing and relative-path normalization
- `KnowledgeService`
  - query input loading
  - coherent case-artifact loading
  - retrieval-document source-path precedence with fallback
- M8.1 migration
  - `CandidateLoader` consumes `KnowledgeService`
  - `m81_candidate_runner` acts as composition root
  - output schema and business behavior remain unchanged
- Regression coverage for repository, service, complete context and partial context paths.

## Compatibility

No CLI parameter, schema, output directory or analysis-context contract was changed.
