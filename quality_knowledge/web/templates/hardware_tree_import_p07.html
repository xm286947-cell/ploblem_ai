Step 5 · Confirm Apply

Apply 将创建新的 Tree Version；若失败，当前 ACTIVE Version 保持不变。

SUCCESS全部生效 · 排除 0 · 失败 0
APPLIED_WITH_EXCLUSIONSApply 前已有明确排除，其余 Change Set Atomic Apply 成功
APPLY_FAILED任一正式变更失败即整体失败；不生成新 ACTIVE Version
Atomic Apply：任一正式变更失败即整体失败，不生成新 ACTIVE Version，绝不显示“部分成功”。
